# **App Name**: Hábitat Next

## Core Features:

- Hero Section: Display a hero image with a title and description. The image will transition automatically every 5 seconds.
- Navigation Dots: Add navigation dots at the bottom of the hero section to allow manual image selection.
- Dynamic Images: Dynamically fetch images from Lorem Picsum to populate the slideshow.
- Text generation: AI tool generates random 'lorem ipsum' text for the hero section title and description.

## Style Guidelines:

- Primary color: Soft teal (#63BDBD) for a calming, trustworthy feel, hinting at nature and domesticity.
- Background color: Very light teal (#E0F2F2), almost white, but subtly desaturated, for a clean backdrop.
- Accent color: Muted sea green (#8FBC8F) to provide contrast on key interactive elements, maintaining the natural feel.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and accessible design, suitable for both headlines and body text.
- Use simple, outlined icons for navigation, to maintain a minimalist aesthetic.
- Smooth transitions between images and dot selections to improve user experience.
- Center the hero content to focus user attention and create a balanced design.
